BUILD A COMPLETE PROFESSIONAL WEB APP CALLED:

"CreatorFlow AI"

TAGLINE:
"Your AI-powered toolkit for smarter content creation."

IMPORTANT:
Build this as a polished, production-style web application, not a simple demo.
The UI must look modern, premium, clean, fast, responsive and trustworthy.
The application must work properly on both mobile and desktop.

==================================================
1. CORE PURPOSE
==================================================

CreatorFlow AI is an AI-powered content creation toolkit for YouTube,
Instagram, TikTok and other content creators.

The user enters a topic, selects a platform and content type, and the
application generates useful content assets.

The main goal is to help creators quickly create:

- Video ideas
- Titles
- Hooks
- Descriptions
- Content outlines
- Thumbnail concepts
- Hashtag suggestions
- Content calendars

Do not create fake AI results.
Use the Gemini API through the environment/API configuration available
to the application.
